# Agente Infratel

Automação inteligente para sistemas Infratel/Claro. Este agente automatiza o preenchimento de formulários técnicos e a geração de relatórios, garantindo precisão e agilidade no fluxo de trabalho.

## Funcionalidades
- **Automação de Sistemas**: Integração direta com portais Infratel/Claro.
- **Preenchimento Inteligente**: Extração e inserção de dados técnicos sem erro humano.
- **Relatórios Automatizados**: Geração de documentos técnicos em tempo real.
- **Interface Simplificada**: Operação intuitiva através de interface web local.

## Como Usar (Versão Portable)
1. Baixe o arquivo `agente_infra_portable.exe`.
2. Certifique-se de que a pasta `.playwright-browsers` está no mesmo diretório que o executável (necessário para o motor do navegador).
3. Execute o arquivo (não requer instalação de Python).
4. Configure suas credenciais no arquivo `.env` (será criado automaticamente no primeiro uso ou use o `.env.example`).

## Desenvolvimento
Para rodar o código fonte:
1. Instale as dependências: `pip install -r requirements.txt`
2. Configure o ambiente virtual.
3. Execute o script principal: `python bot.py`
